# OpenGameInterop Scoop Bucket

[![CI](https://github.com/OpenGameInterop/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/OpenGameInterop/scoop-bucket/actions/workflows/ci.yml)

Install WF Observer with [Scoop](https://scoop.sh):

```powershell
scoop bucket add opengameinterop https://github.com/OpenGameInterop/scoop-bucket
scoop install opengameinterop/wf-observer
```
