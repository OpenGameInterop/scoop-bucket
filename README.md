# Open-WF Scoop Bucket

[![CI](https://github.com/Open-WF/scoop-bucket/actions/workflows/ci.yml/badge.svg)](https://github.com/Open-WF/scoop-bucket/actions/workflows/ci.yml)

Install WF Observer with [Scoop](https://scoop.sh):

```powershell
scoop bucket add open-wf https://github.com/Open-WF/scoop-bucket
scoop install open-wf/wf-observer
```
